# Python Basics

Created: 2026-04-12T13:38:30.661Z
Tags: programming, python

Python is a dynamically typed language, which means that the type of a variable is determined at runtime rather than in advance. This feature allows for more flexibility in coding and can lead to faster development times. However, it also means that type errors can sometimes only be caught when the code is actually executed, which might lead to runtime errors if not properly handled.
