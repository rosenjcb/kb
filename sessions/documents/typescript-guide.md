# TypeScript Guide

Created: 2026-04-12T13:38:53.169Z
Tags: programming, typescript

TypeScript is a programming language developed and maintained by Microsoft. It is a strict syntactical superset of JavaScript, and adds optional static typing to the language.

TypeScript uses static typing to help developers manage larger code bases and catch errors early in the development process. This feature is one of the key advantages of using TypeScript over plain JavaScript.
