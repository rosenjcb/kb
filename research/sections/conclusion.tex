\section{Conclusion}
\label{sec:conclusion}

We introduced KB, a local-first, facts-first codebase knowledge system.
KB's deterministic AST indexing and multi-pond BFS retrieval provide
agents with structured, persistent codebase knowledge without per-session re-exploration.
\texttt{kb query} now uses one-shot synthesis over a capped fact pool, cutting eval
token cost by ${\sim}$70\% while maintaining competitive rubric scores on the KB
self-check suite ($S_K = 0.84$, pass rate $0.75$).

We also introduced MOEL, a multi-objective evaluation framework spanning two pipelines:
(1)~the harvest runner, whose headline grade is $\Delta S = S_K - S_N$ from a single
artifact comparing \texttt{kb query} to a real coding agent on the same eight questions;
and (2)~the deep MOEL harness ($L_\text{MOEL}$), which measures exploration loss under
N/K/O conditions per task.  Bias-mitigated jury ensemble, statistical calibration, and
programmatic validators distinguish efficient exploration from expensive correctness.

\paragraph{Limitations.}

\textbf{Paired $\Delta S$ requires both eval phases.}  Kb-only runs report $S_K$ but
cannot emit the headline verdict until the control agent runs in the same artifact.

\textbf{Calibration sample size is small.}  The 20-sample human-annotated
dataset is sufficient for per-judge logistic regression but does not support
fine-grained calibration per rubric axis.

\textbf{Knowledge base scope.}  KB currently operates on per-file ASTs.
Cross-file dependencies are captured through edge relationships but are not modeled
explicitly at init time.

\paragraph{Future Work.}

\begin{itemize}
  \item \textbf{Full MOEL N/K/O runs}: execute the \texttt{moel-kb} task library under
    all three conditions and report $L_\text{MOEL}$ per task.
  \item \textbf{Raylib $\Delta S$}: complete a paired kb+control harvest on the
    external raylib suite with one-shot synthesis and report $\Delta S$.
  \item \textbf{Synthesis accuracy}: reduce caller-tracing and contradictory-fact errors
    on architecture questions without restoring unbounded multi-turn token cost.
  \item \textbf{Calibration expansion}: grow the human-annotated set to 100+
    samples with axis-level labels.
\end{itemize}

\paragraph{Reproducibility.}

Evaluation artifacts live under
\texttt{\textasciitilde/.kb/evaluations/<run-name>/artifact.json} (schema version~2).
Question packs: \texttt{eval/suites/\{raylib,kb,fzf\}.yaml}.
Headline grade: \texttt{comparison.success\_score.delta\_kb\_minus\_control}.
Implementation: \texttt{scripts/eval-run.mjs}, \texttt{scripts/eval-shared.mjs},
\texttt{scripts/control-core.mjs}, \texttt{eval/losses/}.
