# Reference checklist

- documentTitle: Short KB title (about 3–10 words). **Surface or topic label** (e.g. `kb base commands`) — not a full sentence; no trailing period.
- subject: What API, CLI, or surface does this document cover?
- surfaces: Entry points (commands, types, modules) to list.
- params: Inputs, flags, env vars, defaults, constraints.
- invariants: Rules that always hold (errors, ordering, side effects).
- examples: Minimal copy-paste examples the doc must include.
