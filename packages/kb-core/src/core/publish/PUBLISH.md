# Publish

Export the SQLite knowledge base to an external sink. Publish reads **active** docs from `.kb-index.sqlite` — it does not re-run init or LLM synthesis. The sink uses wipe-and-replace: lane contents are cleared, then rewritten; items no longer in SQLite are removed.

## Role in the stack

```mermaid
flowchart LR
  SQLite[".kb-index.sqlite"] --> partition["partitionPublishDocsByOriginalFlag"]
  partition --> Notion["syncDocsToNotion"]
  Notion --> API["Notion section pages"]
```

Documents are both retrieval units and publish-facing artifacts; publish renders the stored document bodies (see [`../facts-architecture.md`](../facts-architecture.md)).

## Core pieces

| File | Role |
|---|---|
| `publish-docs.ts` | Shared doc row type + lane split |
| `notion-sync.ts` | Archive section children; recreate doc pages |

| `cli/publish-cli.ts` | Command entrypoint |

## Integration

```bash
kb publish notion [--base <name>] [--parent-page-id <id>] [--apply]
```

Lanes: `is_original === 1` → originals; else autogenerated. CLI defaults to preview; pass `--apply` to write (TUI auto-applies — see [`../../cli/CLI.md`](../../cli/CLI.md)). Notion needs `notion.token` + `notion.parentPageId`.

## Sync semantics

1. Load publishable docs (`listPublishableDocs`).
2. Preview: return `written`, `removed`, `skipped` without mutating the sink.
3. Apply: wipe each lane, write current docs.

Notion archives section child pages (IDs in `.kb-publish-notion.json`).

## Invariants

- Read SQLite only — never publish from disk markdown directly.
- Apply must remove stale sink entries absent from the current doc set.
- Skip empty titles; record in `skipped`.

## Extension checklist

- [ ] Route new lanes in `publish-docs.ts`, then both sync modules.
- [ ] Mirror preview/apply/removed/skipped shape for new sinks.
- [ ] Add `tests/core/` + `tests/cli/` coverage.

## Gotchas

- Notion removal matches page title within a section.
- First Notion publish creates `{baseName} — KB Publish` under the parent page.
- Empty SQLite + `--apply` clears published lane content.
