# Howto checklist

- documentTitle: Short KB title (about 3–10 words). **Procedure or topic label** (e.g. `Initializing a project KB with kb init`) — not a full sentence; no trailing period.
- goal: What outcome should the reader achieve?
- prereqs: What must be true before starting (tools, access, versions)?
- steps: Numbered or bulleted steps (be concrete).
- gotchas: What breaks or confuses people?
- verify: How does the reader confirm success?
