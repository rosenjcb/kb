# Decision checklist

- documentTitle: Short KB title (about 3–10 words). **Decision label** (e.g. `SQLite hybrid search default`) — not a full sentence; no trailing period.
- context: What problem or constraint forced a choice?
- choice: What did we decide (one sentence)?
- alternatives: What else was considered and why rejected?
- consequences: Trade-offs, follow-up work, owners?
