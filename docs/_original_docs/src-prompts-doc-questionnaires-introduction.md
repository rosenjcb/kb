# Introduction checklist

- documentTitle: Short KB title for this page (about 3–10 words). **Noun-style topic label** (e.g. `KB overview for developers using AI tools`) — not a full sentence; no trailing period.
- audience: Who is this for (role + familiarity)?
- oneLineThesis: One sentence: what is this system or topic?
- mentalModel: Core concepts / how pieces fit (short).
- boundaries: What is explicitly out of scope?
- nextLinks: Where should the reader go next (doc names or areas)?
